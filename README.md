# UELAi

Modern AI-themed portfolio / showcase website built with pure HTML, CSS, and JavaScript.  
Features a clean responsive design and a chatbot concept interface.

## About

UELAi is a front-end project created to practice modern web design patterns, responsive layouts, and interactive UI elements.  
It presents an AI-focused visual identity with smooth styling and a conceptual chatbot section.

## Features

- Fully responsive design
- Clean modern UI
- Chatbot concept interface
- Custom CSS animations and layout
- Vanilla JavaScript interactivity
- Image gallery / visual sections

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```
├── index.html
├── style.css
├── script.js
├── logo.png / image*.jpg
└── README.md
```

## How to Run Locally

```bash
git clone https://github.com/ankitsapkota2002-boop/UELAi.git
cd UELAi
# Open index.html in your browser
```

No build step or package installation required.
